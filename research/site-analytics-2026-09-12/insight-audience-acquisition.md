## 9. Форк «ChemDB» на нашем счётчике (vojtajanda.eu)

- В Logs API с 2026-07-22 по 2026-09-04 — **139 хитов от 12 clientID, все из Чехии**, с URL `http://localhost/SpaceStationRecepies/` (36), `http://127.0.0.1/SpaceStationRecepies/` (10), `https://vojtajanda.eu/ss14-chem/` (13) и событиями `goal://vojtajanda.eu/<наши события>` (reagent_open, search_used, tab_calculator, batch_plan, tutorial_start, pin_callout_*), а также собственными `feedback_open` (5) и `critical_error` (1) и кликами `mailto:support@vojtajanda.eu?subject=ChemDB feedback…` (5).
- Это чей-то форк сайта под именем «ChemDB» с нашим `ym(108585248, …)` внутри. Фильтр счётчика «только зеркала» вырезал их визиты из Reporting API (в отчётах выше чужого трафика нет), но хиты в Logs API сохраняются, а в отчёте внешних ссылок их клики видны.
- Проверка 2026-09-12: `https://vojtajanda.eu/` отдаёт 403 («NUH UH / YOU DONT HAVE ACCESS»), путь `/ss14-chem/` недоступен; сам сайт существовал как минимум 13 просмотров. В нашем репозитории строк `vojtajanda`/`ChemDB feedback` нет.
- Значение для серии I (лицензия и IP): GPL-3.0 форк разрешает, но копия обязана сохранять лицензию и авторство, а наш идентификатор счётчика туда попал по недосмотру форкера — их пользователи отправляют данные нам. Предложение: (а) инициализировать Метрику только при `location.hostname === 'mikameo.github.io'`; (б) написать на `support@vojtajanda.eu` с просьбой заменить счётчик и проверить атрибуцию; (в) периодически смотреть `goal://<host>` в Logs API как детектор зеркал.
