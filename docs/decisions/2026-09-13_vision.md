# Decision: VISION.md v1.0 — первый Vision-документ проекта

**Date:** 2026-09-13
**Tier:** 2 (документ верхнего уровня иерархии Vision > ROADMAP > задачи; задаёт ставки для всех серий ROADMAP)
**Status:** accepted — утверждён владельцем синхронно в сессии («Утверждаю, меняй статус»), без war-room: документ собран из уже принятых решений и данных, новых кросс-модульных решений не вводит.
**Method:** сбор входов (README, ROADMAP, AUDIT, исследование спроса O1–O11, чекпойнт-3 аналитики, записи решений по лицензии и тактической карте, снимок хаба SS14 от 2026-09-13), сверка со структурой Vision-документов других проектов владельца (общие блоки: шапка со статусом, миссия и позиционирование, аудитория, ядро продукта, принципы, North Star, ставки, стоп-якорь, трассируемость), самопроверка ссылок и утверждений, ревью владельца.

## Context

ROADMAP с версии 1.0 помечал разрыв иерархии: «Vision-документ отсутствует, рабочая замена README + SUMMARY §1». Пока все серии расширяли справочник, разрыв был терпим. Обсуждение командного планшета для офицеров морпехов (2026-09-13) впервые поставило вопрос о смене категории продукта: бэкенд, отношения с администрациями серверов, модерация. Такое решение нужно принимать от Vision, а не от ROADMAP.

## Decision

**Chosen:** [VISION.md](../../VISION.md) v1.0 в корне репозитория рядом с ROADMAP.md и AUDIT.md. Содержание: миссия «сделать глубокие системы SS14 прозрачными для игрока любого форка, не нарушая правил серверов»; четыре сегмента (ядро химиков и медиков, русскоязычные игроки, морпехи, сообщества форков); три продуктовые линии плюс платформа; восемь принципов (данные из кода по закреплённому SHA, форк первичен, правила серверов как граница, RU и EN равноправны, без аккаунтов и ПД, ядро бесплатно, AGPL и DCO, решения по данным); North Star «возвращающиеся пользователи в неделю»; пять ставок с воротами отмены (справочник как дефолт, RU-first, морпехи, сообщества как канал, коммерциализация после сигнала B2B); стоп-якорь из шести пунктов; правило «серия без ставки не стартует»; открытые вопросы.

**Rationale.** Все утверждения документа опираются на существующие записи и данные, поэтому его можно утвердить решением владельца. Ставка B3 (морпехи) и принцип 3 (правила серверов как граница) дают рамку для решения по командному планшету, которое пойдёт следующим через war-room.

**Rejected.** Длинный Vision по образцу других проектов (500–1300 строк) — владелец просил короткий; структура целевого состояния «экран за экраном» — не нужна для статического сайта с workbook в ROADMAP.

**Conditions to revisit.** Смена категории продукта (новая аудитория, бэкенд, сервис), чекпойнт аналитики, отмена или добавление ставки — по правилу раздела 8 Vision, всегда с новой записью в `docs/decisions/`.

## Consequences

- Шапка ROADMAP ссылается на VISION.md; каждая новая серия обязана указывать ставку из VISION §6.
- Проектный CLAUDE.md создан со ссылкой на Vision (требование глобальных правил).
- Следующее решение: командный планшет для офицеров, серия после T, war-room обязателен (бэкенд, интеграция с сообществами, правила серверов).
