# U1 — «Нетерпеливый новый пользователь» + выборочные проверки доступности и хаоса

Быстрый инкрементальный аудит, 2026-09-13. Объект: `tactical.html` (RMC14 / LV-624, затем Space Stories) и вход в него через оверлей «Разделы» на `index.html`.

**Уровень браузера:** Browser pane (MCP `Claude_Browser` поверх CDP, вкладка `seed`, `http://localhost:60968`). Клики, наведение, клавиши — реальные события через `computer`; состояние читалось через `read_page` и `javascript_tool`; каждая навигация с уникальным `?nocache=`. Особенности инструмента: вставка из буфера эмулировалась синтетическим `ClipboardEvent` с `DataTransfer` (реальный Ctrl+V недоступен); клавиша `Return` панелью не доставляется, `Enter` доставляется; скриншот иногда отстаёт на один кадр, поэтому выводы делались по `read_page`/JS, а не по картинке. Viewport: 1535×710 (десктоп), 375×812 (mobile preset), в конце сброшен `preset: desktop`.

Стартовое состояние: удалены все ключи `localStorage` с префиксом `chemdb-tactical:` (`rmc14/varadero`, `stories_cm/lv624`, `rmc14/lv624`, `prefs`), язык `chemdb-lang=ru`.
