# U1 — First-time user, zero patience, zero context (UX/UI dept, Round 1)

Agent: U1. Date: 2026-09-11. Target: local preview `http://localhost:64306/` (identical files to prod, HEAD e777079).
Browser level: **Claude Browser pane (CDP, real mouse clicks)**, own tab `tab-1`, viewport 1366x900, fresh `?fresh=` param on every load.
All findings below are `runtime_verified` unless marked otherwise; code citations are added where I could pin the cause.

Method notes / honesty caveats:
- Real clicks were used everywhere. Native `<select>` values were set with `form_input` (fires real events); three scroll positions were set via `scrollTop` purely to reach a section (never to make a claim).
- The `computer{action:"key"}` tool could **not** deliver Backspace/Delete/ctrl+A to a focused `<input>` in this pane (value never changed, focus confirmed on `searchInput`). That is a tool limitation, **not** an app defect — I did not report it, and I cleared fields through the app's own "Clear search" affordance instead.
- `zoom` with a region is not supported in this pane; detail claims come from full screenshots + `getComputedStyle`/`getBoundingClientRect`.
