# T2 — Pen-test + business-logic audit of the browser layer (project-audit v3, Technical dept.)

Repo: `D:/Space Station Recipes` @ e777079 (read-only). Scope: app.js, ordnance.js, i18n.js, maps.js, tutorial.js, sw.js, index.html inline scripts; untrusted inputs = data.json / maps/*/*.json / maps/*/prices.json / ordnance/stories_cm.json (baked from 21 third-party GitHub repos), URL hash/query, localStorage, the Yandex.Metrika tag.

Evidence types used: `code_verified` (read the source), `code_verified+node` (function executed in a node harness against the real data.json / ordnance JSON — scratch copies only, see "Files examined"), `data_scan` (python scan of the committed JSON), `http_fetch_only` (upstream C# fetched from raw.githubusercontent.com). No browser runtime was used (UX dept. does that); anything that needs a browser is marked UNCERTAIN.

Method notes: every `innerHTML`/`insertAdjacentHTML` sink in the six files was enumerated by grep (88 sites) and each interpolation traced to `esc()` (app.js:2163) / the ordnance `esc` (ordnance.js:75) / the local `escapeHtml` (app.js:842). data.json (1387 reagents, 1104 reactions, 152 plants), all 114 map JSONs (243,135 items, 2.5k vias, beacons), 15 prices.json and ordnance/stories_cm.json were scanned for `<`, `>`, `&`, `"`, `'`, `javascript:`. Logic was executed, not only read: `calculateIngredients`, `mergeSteps`, `planBatch`, `buildCraftTree`, `simulateBeaker`, `recipeSteps`, `sortResults`, `reagentInFork`, `getFilteredReactions`, `healPerUnit`, `levenshtein`, and the ordnance closure (`computeStats`, `reqSearch`, `reqLadderRows`, `loadMasks`, `costOf`) via an exported scratch copy; `computeStats` was diffed against `ss14_ordnance.compute_stats()` on 2,577 mixtures.

## A. XSS & injection

### A.0 Data-scan verdict (data_scan)
- **No live payload in the committed data.** Zero occurrences of `<`, `>` or `javascript:` in any display string of data.json (name/desc/flavor/physicalDesc/nameRu/descRu/obtainSources/category/effectTags/plants.name/meta.forks.name), in all 243,135 map item names, 2,516 vias and every beacon name, or in ordnance/stories_cm.json. The 1,365 `<`/`>` hits are all inside `effects`/`verifiedMechanics` comparator text ("body temp < 203K") and those fields are escaped at every sink (app.js:915, 1286, 2698).
- All 1387 reagent ids, 1104 reaction ids, 152 plant ids and 243k map pids match `^[A-Za-z0-9_.-]+$`; effectTags match `^[a-z0-9:_-]+$`; every fork colour is `#rrggbb`; sources.py URLs are all `https:`.
- Quote characters DO occur (11 names such as `Demon's Blood`, 3 `nameRu` with `"`, 18,231 map names / 2,516 vias with `'`), which matters for the attribute/onclick sinks below.
- The extractors have no sanitiser: `ss14_chem_extractor.py` and `ss14_map_extractor.py` copy FTL/YAML text verbatim (map names: ss14_map_extractor.py:552, 774). The browser is the only line of defence.
